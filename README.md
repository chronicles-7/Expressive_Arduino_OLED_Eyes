# Expressive_Arduino_OLED_Eyes
This is git includes code and instruction on how to turn a button, Arduino UNO, and a 1.3 inch OLED display into an expressive, cute Tamagochi-style virtual pet that has 4 emotions: Idle, Sleeping, Alert, and Angry, based on situation and button press. Further instruction and how-to guide is provided in README. Hope you like it!
